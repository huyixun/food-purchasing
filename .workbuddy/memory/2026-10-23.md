## SVG 导出 PNG

- 已导出 `docs/process-flow-annotated.png` 与 `docs/process-flow.png`，均 2400×3480（2.4×，约可印 A3）。
- 转换方案（可复用）：在 `C:/Users/86136/.workbuddy/binaries/node/workspace` 装了 `@resvg/resvg-js`，脚本 `render.js` 用 fitTo width=2400 + loadSystemFonts + defaultFontFamily 'Microsoft YaHei'。运行：`node render.js`。
- **重要**：resvg 不支持 `context-stroke`，箭头会整条丢失；必须给 marker 写死 stroke 色，并按颜色拆 marker（arrow / arrowRed / arrowLoop）。另：竖向连接线原来那组 `<g>` 漏了 `marker-end`，已补。
- 改图流程：改 svg → `node render.js` 出图 → 用 python 正则把 `<div class="figure"><svg…/></svg>` 换成新 svg 同步进 HTML，否则 HTML 里是旧图。
- 校验技巧：resvg 直接裁剪 viewBox 会 panic；改用「SVG 里放 `<image href="data:image/png;base64,…">` + 小 viewBox」裁局部看细节。

- 关键经验（下次直接复用）：
  1. **转换引擎支持 CSS 变量**（`var(--x)` 实测落成 `w:sz`/`w:color`），所以样式全走 `:root` 令牌可同时满足 html-review 的 DT-01~05。

  3. html-review 硬规则：每文档只能 1 个 `<h1>`（正文标题），章节用 h2/h3；章节 h2 后必须紧跟正文导语（TQ-03）；每张表需 thead/tbody；`<ol>` 不能直接嵌 `<ol>`（TOC 子级要放进父 `li`）；封面文字用 `<div>` 不用 `<p>`（TQ-06 字号一致性）；business-report 必须有 `.executive-summary`。
  4. 有封面/页码时禁止 `--no-preflight`，须 `--require-page-furniture`。
