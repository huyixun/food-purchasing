## 二、由材料推导、不再提问的硬约束

- **永久只读**：自助下单、延长效期、替换配方（f32）；效期修改与检验放行，异常批次仅质量人员可隔离（f40、f05、f52）
- **写入语义**：只追加更正，**严禁覆盖原记录**（f15）
- **交接语义**：含业务编号 / 版本 / 状态 / 未决事项 / 接手人；对方确认接手才算完成，发消息不算（f23）
- **转人工**：促销取消已解冻、资料缺依据、双版本冲突、关键系统不可用（f44）
- 硬基准：每日 9000 份、核对 3h；损耗 11%→6%、缺配 7%→2%（f00、f12，目标值非基线）
- 预算：15 万含集成 / 培训 / 验证（f03）
